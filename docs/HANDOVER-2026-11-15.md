# WWE '13 Android port - progress notes (2026-11-15)

## Build
Run `tools/build_apk.sh` (copy lives at /workspaces/build_apk.sh). It builds+installs the SDK in BOTH Release and
RelWithDebInfo (the game links librexcorerd.a = RelWithDebInfo; installing only Release leaves it stale), forces a
libmain.so relink (installed libs keep old mtimes so ninja skips the link), strips, runs gradle, prints the Termux line.
A good run shows "Linking CXX shared library libmain.so", BUILD SUCCESSFUL and thermal_in_libmain=1.

## Verified on device
- Landscape lock: SDL_SetHint(SDL_HINT_ORIENTATIONS) first thing in SDL_main (SDK windowed_app_main_android.cpp).
- Thermal log line [rate-census-thermal] every second. Result: GPU peaked 53.6C, CPU 58.4C -> NOT throttling.
- GPU timing buckets split: guest_index_copy, memexport_readback_full/fast, scaled_readback, gpu_written_readback.
  All read 0 in matches; the real cost is VulkanSharedMemory::UploadRanges.
- [upload-census]: in a match ~2000-2800 uploads/s (~150/frame), ~9 KiB each, ~1.3 MiB/frame. Many small uploads,
  and each ends the render pass (SubmitBarriers(true)) -> ~13 ms/frame on Adreno 810.

## Match GPU cost per frame (~53 ms, ~17 FPS)
rt_transfer ~21 ms (1100 passes), shared_memory_upload ~13 ms, texture_load ~11 ms, resolve ~3.5, edram_dump ~2.9.

## In progress (NOT build-verified yet)
Hoist census (vulkan_upload_hoist=1, count-only, launch.cpp passes it on Android): counts uploads whose pages nothing
earlier in the submission touched. Next: read [hoist-census] in a match log. If >= ~half hoistable, build the hoist
stream (second DeferredCommandBuffer replayed first, in sync path and submission worker, closing barrier per 2K14
patch 098). Reference: 2K14 patch 009 (vulkan_upload_hoist). 2K14's gpu_native_* renderer is NOT portable.
